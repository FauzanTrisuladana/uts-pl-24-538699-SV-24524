# Konfigurasi Inisialisasi Proyek Vue.js (`pnpm create vue@latest`)

Berikut adalah opsi konfigurasi yang dipilih saat membuat proyek frontend Vue.js menggunakan perintah `pnpm create vue@latest`:

1. **Project name (target directory):** `frontend`
2. **Use TypeScript?** `Yes`
3. **Select features to include in your project:**
   - `Router (SPA development)`
   - `Vitest (unit testing)`
   - `Linter (error prevention)`
   - `Prettier (code formatting)`
4. **Select experimental features to include in your project:** `none`
5. **Skip all example code and start with a blank Vue project?** `Yes`
